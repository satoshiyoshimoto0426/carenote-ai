## 3. フェーズ一覧（依存順・並行レーン明記）

### 【最優先・外部待ちを先に始める】P-LEGAL-C｜説明責任の書類を仕上げる ★G1

> Anthropic への照会は 2026-07-19 に決着済み（DPA は商用条件に組込済・署名不要。ZDR は $100K+ コミット条件のため見送り＝代替は30日自動削除＋学習不使用＋仮名化）。**残りは自前の書類だけ**。

- 👤🏢 **データ取扱説明書 v0.5 の専門家レビュー**（弁護士／行政書士）。争点は3つ:
  1. 録音の文字起こし（Genspark SecondBrain・個人プラン）── 同社規約が「健康状態等の機微な個人情報は収集しない」と明記＝介護記録は想定範囲外。**委託／第三者提供のどちらで整理するか**、法第28条の情報提供の内容
  2. 要配慮個人情報を海外事業者へ渡す構成（Anthropic・OpenAI）の同意方式 or 相当措置方式の選択
  3. 保存期間の起算（作成日 → **完結の日**）と自治体条例との整合
- 🧩👤 **合意書・利用者説明文・同意書のひな型**の作成 → 専門家レビュー（Claude がたたき台を書く）
- 👤 **職員の誓約書**と**退職時の停止手順**（アカウント・拡張トークンの失効手順は `docs/EXTENSION-TOKENS.md`）
- 👤 プライバシーポリシーに米国処理・越境移転を明記
- 🧩 レビュー結果を DATA-HANDLING-EXPLANATION.md へ反映 → v1.0（正式版・記名押印欄つき）

### P-KPI｜合否基準を先に決める ★G4

- 👤🏢 **実証開始前に**現行の作成時間・品質のばらつきをベースライン計測
- 🏢👤 成功閾値を先方と数値合意（例: 1件30分→15分／評価スコアのばらつき30%減）
- ベースラインは**2条件**（①コピペ運用 ②拡張流し込み）── 規約NGでもコピペ単体の価値を数値で示せる保険

### P-GEN / K1｜生成品質の実データ確定と知見エンジン

- 👤 実証帳票を**1〜2種に絞る**（第5表＝実地指導の要、または第1・2表＝主戦場）
- 👤🧩 知見（作成ポイント）を `lib/rules/` へ反映 → 再生成 → 吉本さんの目視＋評価エンジンで較正
- 🧩 ルール更新のたびに評価エンジンで**回帰採点**（P-EVAL）
- 公式文書の扱い: 法令・告示・通達は取込可（著作権法13条）。白書・手引きは**要旨をルール化＋出典明示**（全文転載しない）

### P-LAUNCH｜1社実証ローンチ ★G6

- ✅ 人間承認のデータモデル強制（実装・実機検証済 2026-07-19）
- 👤 価値訴求は「作成時間の短縮＋記載漏れの**検知補助**」に限定（監査リスク低減の保証とは謳わない）
- 👤🏢 KPI の after 計測 → ベースラインと比較 → 先方と合否判定
- 🧩 出荷前チェック（`/ship` または graph-ship）＋ 独立審査（graph-doubt）を再実行

> 1社実証ローンチ後の拡張路線。「AIは書く係と見張り係、カイポケは計算係、人間は決める係」の分担を守る。

| 段階 | 内容 | 状態 |
|---|---|---|
| V1 | 1次情報（診療情報提供書・主治医意見書・看護サマリー）のAI統合分析→帳票生成 | ✅ 実装済（第6段 OCR統合）。手書き精度の実測が残る |
| V2 | **5帳票すべて**をカイポケへ流し込み | 🔜 アセスメント10ページ・第2表は実装済。第3表・第4表・モニタリングは未 |
| V3 | 承認済み書類を利用者ページから拡張へ渡す（生成し直し不要） | 🔜 lite=「カイポケ用データをコピー」→パネル貼り付け |
| V4 | 利用票・提供票は**転記補助まで**（計算はカイポケ） | 構想 |
| V5 | 請求は**AIが検算・突合して指摘、実行は人間＋カイポケ** | 構想 |
| V6 | 音声起点の記録（a 文字起こし貼り付け ✅ / b 音声アップ→自動判定 / c 予定の自動登録） | a・c の入口は実装済（カレンダーはリンクと .ics） |

## 6. 最重要リスク（2026-09-12 時点）

1. **R-LEGAL**（最大）: 録音の文字起こし事業者（Genspark 個人プラン）に DPA が無く、同社規約が機微情報を想定していない。専門家レビュー次第で**録音経路を差し替える**（スマホ録音 → CareNote → OpenAI。実装済み・切替可能）
2. **R-KAIPOKE**: 規約NG／実機NGなら転記がコピペへ縮退（2条件KPIで価値を担保）
3. **R-FIELD**: 全6段が**実機未確認**。動く証拠はテストとビルドのみ ── 実機16項目が最短の解消手段
4. **R-RETENTION**: 保持期限後の自動削除が未実装（説明書で「開発中」と正直に開示中）。手動対応の運用が回るか
5. **R-KNOWLEDGE**: 知見エンジンの律速は吉本さんの言語化時間（テンプレと反映運用の固定で軽減）
6. **R-RESPONSIBILITY**: 「AIが制度準拠を判断」は保証できない → 承認データモデル＋訴求限定＋人間の最終確認で設計として担保
