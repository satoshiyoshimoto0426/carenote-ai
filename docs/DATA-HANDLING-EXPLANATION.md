## 1. この資料の目的

CareNote AI（介護記録の作成補助サービス）の導入にあたり、貴法人の利用者様の個人情報——とくに
**要配慮個人情報**（心身の状態・介護の記録など）——を**どのような仕組みで、どこまで、どう守って**
扱うのかをご説明するものです。個人情報保護法の**委託先の監督**（法第25条）のための資料としても
お使いいただけます。

## 3. データの流れ（何が・どこへ行くか）

```
⓪ 録音（該当する場合）── 電話・面談・サービス担当者会議・モニタリング訪問
     ・CareNote AI の画面で録音するか、手元の録音ファイルを選ぶ
       → **米国 OpenAI社の文字起こしサービス**へ送って文字にする（**音声は原音のまま渡ります**。§5-2）
       → 文字になったものが ① のメモ欄に入り、以降は通常どおり記号化と職員の確認を通る
     ・音声は CareNote AI にも職員のパソコンにも**保存しません**（文字になった時点で消えます）
     ・長い会議は5分ごとに区切って送ります（1回に送れる大きさに上限があるため）
     ・録音の冒頭で「記録のため録音します」と**その場の全員に伝える**運用（法第21条の利用目的の公表）。
       担当者会議では議事録（第4表）にも「録音して記録を作成」と残します
     ・雑談や他の利用者の話になったときは**一時停止**します（録らなければ外に出ません）
① 職員がメモ・資料を入力
     ・登録済み利用者の氏名は自動で記号化（例:「山田花子」→「A様」）してからAIへ
     ・電話番号・住所・生年月日等も自動で「〔電話番号1〕」等に置換。送信前に職員が画面で確認
       （名前らしい言葉が残っていれば赤く表示。職員が直すか、そのまま送るかを判断）
     ・実名そのものは暗号化して別領域に保管（AIへは渡さない）
        ↓
② AI（Claude API・米国 Anthropic社）が帳票の下書きを生成
        ↓
③ 職員が画面で内容を確認 → 保存した書類は「承認」ボタン（誰が・いつ承認したか記録に残る）
        ↓
④ 職員が介護ソフト（カイポケ）へ転記して確定（確定は常に人間）
```

**大切な例外を正直に**：
- **添付資料（診療情報提供書・主治医意見書・看護サマリー・認定調査票などの PDF、および紙を撮影した画像）は
  原本のまま**AIへ送信されます（実名・病名を含む）。画像の文字読み取り（OCR）も同じ AI（Anthropic）で行い、
  別の読み取り会社へは渡しません。資料は読解処理の後すみやかに削除し、AI側でも30日以内に自動削除・
  学習利用は契約で禁止されています。読み取った文章は職員の画面に出す前に自動記号化を通します。
- **添付資料の一時保管**：資料は読み取りの直前に Vercel 社の保管領域（Blob）へ置き、読み取りが終わると
  すぐ削除します（失敗した時は画面に警告を出します）。この保管領域は**「非公開」設定**（2026-09-12 に切替）で、
  URL を知っていても当方のサーバの認証を通さなければ読めません。ファイル名は拡張子のみ（実名を含む元の名前は使いません）。
- **保存した書類の中の電話番号・住所**は、AI へ送る時は「〔電話番号1〕」等に置き換えますが、AI の返事を職員の画面に
  戻す時に元の番号へ戻し、その形で保存します（職員が確認に使うため）。保存先は鍵つきの保管領域で、氏名だけが暗号化して
  分離されています（2026-09-12 に方針として確定）。
- **ブラウザ拡張から直接生成する場合**（カイポケ画面の横のパネル）は、登録利用者の氏名の記号化は働きません（名簿を
  読まない経路のため）。電話番号・住所等の置き換えと漏れ検査は同じように働きます。拡張の画面では**実名を書かない**
  運用が前提です。
- **記号化が働く範囲は、事業所アカウント（組織）の設定で決まります**。既定では、氏名の記号化は
  **その職員が登録した利用者・関係者に限られます**。事業所の全員ぶんに広げるには、次の3つが
  すべて済んでいる必要があります。
  1. 管理者が事業所アカウント（組織）を作り、職員を所属させる
  2. 管理者が、既に登録済みだった利用者を事業所ぶんへ移す（移行作業）
  3. **各職員が、画面で事業所を選んでいる**（本サービスは「いま選んでいる事業所」を見ます。
     所属しているだけでは切り替わりません）
  3つのうち1つでも欠けていると、**他の職員が登録した方の実名は置き換わらず、そのままAIへ送られます**。
  いまどちらの状態かは、**画面の左下（スマートフォンでは画面上部）に常に表示されます**
  ──「名簿を事業所で共有中」または「名簿は自分の登録分のみ」。ご利用前に必ずご確認ください。
  なお、万一「同じ記号に違う氏名」など名簿の不整合が生じた場合は、本サービスは生成を中止します
  （記号を戻すときに別人の氏名が入るのを防ぐため）。
- 氏名の自動記号化が働くのは**本サービスに登録済みの利用者の氏名と、利用者ごとに登録した関係者
  （ご家族・関係先の担当者など。「A様の長女」等の記号に置換）**です。登録していない方の実名や
  あだ名などは置換できません。そのため**「メモに実名を書かない」を第一の運用ルール**とし、
  自動記号化はその安全網と位置づけています（§7）。送信前には職員が画面で内容を確認します。

## 4. 当方（CareNote AI）が実装している安全管理措置

| 対策 | 内容 |
|---|---|
| 仮名化 | 登録利用者の氏名を記号（A様等）へ自動置換してからAIへ送信。実名はAES-256-GCM（政府機関等でも用いられる強度の暗号化方式）で暗号化し分離保管 |
| 人間承認 | AI出力は常に「下書き」。**保存した書類**は、職員の承認操作（承認者・日時を記録）を経るまでコピー機能が使えない。生成直後の画面にも「下書き・要事実照合」を常時表示 |
| 添付資料の非保持 | アップロードされたPDF・画像は**非公開**の一時保管（認証なしでは読めない・拡張子のみの名前）ののち、処理後**すみやかに削除**（恒久保存しない）。処理が途中で止まった場合も削除。削除に失敗した時は画面に警告 |
| アクセス制御 | ログイン（または発行制トークン）必須。保存書類は作成した職員本人のアカウントに紐づく。※当方（提供者）は保守のため技術的にアクセス可能ですが、障害対応等の必要時に限ります |
| 保持期間 | 保存書類に期限（作成から5年）を記録。**期限経過後の自動削除機能は開発中**で、それまでは求めに応じ手動で削除対応。介護記録の保存義務の起算（完結日基準）や貴法人規程との整合は導入時に協議のうえ設定 |
| 通信の保護 | すべての通信はTLS（インターネット通信を暗号化する標準技術・ブラウザの鍵マークの仕組み）で保護 |
| 第三者による検証 | 2026-09-11 に別の AI による独立審査（30 の検証エージェント）を実施し、指摘された穴（関係者名簿が読めない時に黙って進む・戻した番号を再度 AI へ送る経路・番号の表記ゆれの素通し等）を同日〜翌日に修正。修正は自動テスト（256件・2026-09-12 時点）で固定 |

## 5-2. 録音の文字起こし（OpenAI）── 2026-09-17 に経路を変更しました

> **【変更のお知らせ】** v0.5 まで、録音は Genspark 社の SecondBrain で文字にし、その全文を
> CareNote AI へ貼る運用でした。v0.6 から、**録音は CareNote AI の画面で行い、文字起こしは
> 米国 OpenAI 社へ直接依頼する**方式に変更します。これは §8 の「再委託先の追加・変更は事前に
> 書面で通知」に当たりますので、本資料の改訂をもって通知とし、ご異議があれば協議させてください。
> **変更が完了するまで、CareNote AI の画面内録音は使えない状態にしてあります**（設定で止めています）。

### なぜ変えるか

| 観点 | 従来（Genspark 経由） | 変更後（OpenAI へ直接） |
|---|---|---|
| 音声の行き先 | Genspark → さらに**非公表の処理先AI事業者**（OpenAI/Anthropic/Google/xAI/ElevenLabs のいずれか） | **OpenAI 1社のみ**（どこへ行くかが確定する） |
| 学習への利用 | 個人向けプランの規約に「学習に使わない」の明文なし | **学習に使わない**（公式のデータ管理ページに明記） |
| 監視ログの保持 | 記載なし | **保持なし**（同上・2026-09-11 確認） |
| 音声の保存 | 同社のクラウドに残る（解約後30日以内に削除） | **どこにも保存しない**（受け取って渡し、返ってきた文字だけ返す。職員のパソコンにも残さない） |
| 機微情報の扱い | 同社は「健康状態などの機微な個人情報は収集しない」と明記 ── 介護記録は想定範囲外の可能性 | この懸念は解消 |

**つまり、渡る先が1社に絞られ、学習に使われず、音声が残らない形になります。** 2段階で不特定の
事業者へ渡っていた従来の構成より、説明できる範囲が広がります。

### それでも残る限界（正直に）

- **音声には黒塗り（記号化）が原理的にかかりません。** 文字にしてからでないと名前を置き換えられないため、
  録音した声と、そこに含まれる実名は**そのまま**米国の事業者へ渡ります。担当者会議の録音には、
  利用者・ご家族・他事業所の職員・主治医の氏名が含まれます。
- 文字になったあとは通常どおり記号化と職員の確認（赤い言葉の表示）を通りますが、
  **名簿に登録していない方の名前は自動では消えません**（画面で職員が確認して直します）。
- 録音そのものを行うかどうかは、**その場の全員に伝えたうえで**職員が判断します。
  CareNote AI は、伝えたことの確認にチェックが入るまで録音を始められない作りにしています。
- 米国の事業者である点は従来と同じです（§6 の対応方針が引き続き適用されます）。


## 6. 国外処理について（法第28条への対応）

- AI処理・データ保管等は米国の事業者（§2の表）で行われます（※各社の詳細な処理拠点・リージョンは
  確認中の項目があり、確定次第お知らせします）。
- 対応方針（いずれかを貴法人と協議のうえ確定します）:
  1. **本人同意方式（推奨）**: 重要事項説明書・個人情報利用同意書に外国での処理を明記し同意を得る。
     ※法第28条では、同意取得の際に「**どの国か・その国の個人情報保護制度・提供先の保護措置**」の
     情報提供が必要とされています。この要件を満たす同意書ひな型は当方で用意し、**専門家の確認を経て**提供します。
     ※認知症等で同意能力に課題がある利用者様については、ご家族・成年後見人への説明を含む運用を協議します。
  2. **相当措置方式**: 各社の保護措置が法の求める基準に適合する体制に該当するかを確認のうえ同意に代える。
     **この方式では、相当措置が継続されているかの定期確認と、本人の求めに応じた情報提供が継続的に
     必要になります**（採否は専門家の確認を推奨）。
- いずれの場合も、貴法人のプライバシーポリシー／利用目的の掲示への「外部委託（国外処理を含む）」の
  記載追加をお願いします（文案は当方で用意します）。

## 7. 貴法人にお願いすること（運用ルール）

1. **実在の利用者情報の投入は、本説明の確認と合意書の締結後から**（それまではテストデータのみ）
2. **メモ・入力欄に利用者の実名を書かない**（利用者は先に登録し、記号で呼ぶ。自動記号化は安全網）
3. AI出力は**必ず内容を確認し、承認操作をしてから**使用する運用の徹底
4. 職員アカウントの適切な管理（パスワード・トークンを共有しない。退職時は当方へ連絡→即時停止）
5. §6 の対応方式（同意方式／相当措置方式）の選択
6. **録音**を行う場合（電話・面談・サービス担当者会議・モニタリング訪問）:
   - 録音の冒頭で「記録を作るために録音します」と**その場の全員に伝える**（法第21条の利用目的の公表）。
     担当者会議では議事録（第4表）にも「録音して記録を作成」と残す
   - **出席者のどなたかが断られた場合は録音しない**（手書きに切り替える）運用とするか、貴法人でご判断ください
   - 雑談・他の利用者の話になったら**一時停止**する（録らなければ外に出ません）
   - ご家族・他事業所のご担当者・主治医の氏名は、**あらかじめ「関係者名簿」に登録**しておくと自動で
     記号に置き換わります。登録していない方の名前は画面で職員が直します
   - 録音が途中で文字にならなかった区切りは画面に番号で出ます。その時間の内容は**手で書き足して**ください
